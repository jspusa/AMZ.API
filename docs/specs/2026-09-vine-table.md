# Vine 橫列表格與綁變體提示

使用者要求（2026-09-14）：Vine 進行中改為逐列橫式表格，欄位依序為「品名、ASIN、報名日期、狀況、進度、綁變體」，並在首頁「低頻健檢」提供入口。

- 進度維持 Amazon Vine 評論／已註冊名額及血條；保留完整品名、原始狀況、報名日、搜尋及手動匯入來源時間。
- 已收到評論達註冊名額三分之二時，綠燈顯示「可綁變體」；其餘紅燈顯示「等待Vine回收」。20/30、10/15、22/30 可綁；19/30、9/15、0/30 等待。名額不能整除 3 時向上取整，2/2 可綁、1/2 等待。
- 評論未回報保留未知標示和紅燈，不補零、不顯示可綁。判斷只使用通過既有 snapshot 驗證的評論與註冊數。
- 燈號是使用者自訂營運提示，不是 Amazon 資格判定，也不執行綁定。保留既有本機 GET／明確匯入 POST、加密保存與 context 清除。
- 低頻健檢預設收合；Vine 入口直接開啟既有工作區，回首頁恢復入口焦點，不加入七項 run-all。
- 桌面顯示六欄橫列；小螢幕保留表格並只在表格區水平捲動，完整品名可換行，文字、燈號和血條在深淺色及放大字級仍可辨識。

驗證沿用 VinePanel 的公開顯示／使用者操作 seam，及 Dashboard 的入口／返回 seam；以使用者提供的門檻例子驗證，保留未知與 context 失效回歸。瀏覽器視覺核對使用合成資料。這是 Control Console Release，無 main／preload／DTO／儲存 schema 或 Notebook Key 版本修改。
